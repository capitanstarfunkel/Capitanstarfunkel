¿Cómo funciona el reproductor?

1. El ID del video

Cada video de YouTube tiene un código único en su dirección. Es lo que viene después de v=.

https://www.youtube.com/watch?v=jNQXAC9IVRw
                                 ↑ este es el ID

2. La etiqueta iframe

Un iframe muestra una página dentro de otra. YouTube nos da una dirección especial para eso (/embed/):

<iframe src="https://www.youtube-nocookie.com/embed/ID" allowfullscreen></iframe>

3. Cambiar de video con JavaScript

Los botones guardan el ID del video. Al hacer clic, JavaScript cambia el src del iframe por el nuevo ID.

player.src = "https://www.youtube-nocookie.com/embed/" + id;

4. Enviar el video desde la galería

La galería enlaza a reproductor.html?v=ID. El reproductor lee ese ID de la dirección y carga el video.
